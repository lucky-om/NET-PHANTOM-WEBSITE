Windows Release

Setup Installer

File: NetPhantom_Setup.exe

The official NetPhantom Windows setup installer executable (NetPhantom_Setup.exe). Upon execution, it automatically configures all NetPhantom packet engine modules, installs Npcap drivers, creates Desktop & Start Menu shortcuts, and registers system file associations.

⚡ Download NetPhantom Setup (.exe) Size: 69.4 MB • Version: v3.3.2 (Windows 10 / 11)
🛡️ Windows Defender SmartScreen Note: Because this is a custom open-source binary without an expensive EV Code Signing Certificate, Defender SmartScreen may display "Windows protected your PC".
Click "More info" ➔ "Run anyway". Alternatively, right-click the downloaded NetPhantom_Setup.exe ➔ Properties ➔ Check "Unblock" at the bottom ➔ Click Apply.
PyPI Package

Install via Python Pip

  • Ensure you have Python 3.10+ installed.
Install NetPhantom directly into your global virtual environment using pip:

python -m pip install git+https://github.com/lucky-om/NetPhantom.git
netphantom
Dependencies automatically resolved: scapy, pywifi, Pillow, psutil.
Linux Setup

Linux Auto Installer & Source Build

Run Linux setup installer to auto-install dependencies, grant packet capture capabilities, and register system desktop shortcuts:

git clone https://github.com/lucky-om/NetPhantom.git
cd NetPhantom && sudo bash ./installers/linux/install.sh
netphantom
